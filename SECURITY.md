# Security policy

## Supported versions

Only the latest published StudioFS release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately through GitHub's
[private vulnerability reporting](https://github.com/valandreev/studiofs-cli/security/advisories/new).

Include the affected version or commit, platform, a description of the impact
and the steps to reproduce it. Do not include real credentials, DSNs or
customer data; use redacted or synthetic values.

You should receive an acknowledgement within seven days. Fixes are released as
a new version, and the advisory is published once a fix is available.
