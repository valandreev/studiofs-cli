# Bound regular encrypted payload downloads

This living ExecPlan follows `.agent/PLANS.md`.

## Purpose / Big Picture

SFS-862 prevents a cold file read from buffering an arbitrarily large object-store response. Regular fragments must stop reading on invalid SFEC geometry or bytes beyond that geometry. Snapshot artifacts retain the generic full-read policy because metadata artifacts may exceed a regular fragment.

## Surprises & Discoveries

Codebase Memory MCP returned Transport closed; its CLI returned exact-build admission could not be verified. Direct source reads and literal searches provide discovery fallback. OpenDAL 0.55 Reader::into_stream(..) without chunking streams underlying buffers without first collecting the response or relying on advertised length.

## Decision Log

Use a dedicated regular-payload fetch method rather than shrinking get_by_key_with_stats, which also serves generic objects. Validate the fixed SFEC prefix incrementally, require plaintext length no greater than CLOUD_FRAGMENT_SIZE plus ObjectHeader::SIZE, then enforce the exact encrypted length derived from header and frame geometry. This supports historical nondefault frame sizes without arbitrary constants. Preserve nonretryable malformed-envelope errors and segmented buffers.

## Context and Orientation

`crates/studiofs-data/src/store.rs` decrypts encrypted objects after OpenDAL reads. `crates/studiofs-data/src/envelope.rs` validates SFEC (the encrypted wire format) and computes frame lengths. `crates/studiofs-vfs/src/fetch.rs` downloads regular fragments in demand and prefetch paths. STFS is the inner plaintext object header; the largest fragment contains CLOUD_FRAGMENT_SIZE payload bytes plus that header. Snapshot artifacts use a separately typed key and the generic full-read API.

## Plan of Work

Add DataStore::get_payload_by_key_with_stats and route the two VFS regular full reads through it. Read SFEC prefix bytes across arbitrary buffer boundaries, reject excessive declared plaintext, derive exact ciphertext length, check actual bytes before retaining each buffer, and decrypt only after EOF. Keep existing generic and snapshot APIs unchanged. Add a fake accessor returning segmented body buffers and a misleading RpRead size; record byte consumption to prove early termination. Add valid-boundary and larger-snapshot round trips plus a VFS cache-rejection regression.

## Validation and Acceptance

An oversized fake response must fail with a nonretryable format error after consuming only its prefix or at most the declared encrypted size plus one returned accessor buffer; it must leave the remainder unread even if RpRead advertises fewer bytes. Valid 4 MiB payloads must decrypt, and a typed snapshot larger than 4 MiB must still round-trip. VFS must reject excessive data without caching it.
