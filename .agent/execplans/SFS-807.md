# Move macFUSE memory sampling out of open callbacks

This living ExecPlan follows `.agent/PLANS.md`.

## Purpose / Big Picture

Concurrent file opens must not queue behind an OS memory measurement. Read-only files keep kernel caching (UBC and readahead) only when a fresh estimate shows they fit. Missing or stale telemetry selects direct I/O, and local VFS payload caching still works. Memory-driven direct I/O must be observable, and the estimate must not report zero on ordinary Macs.

## Surprises & Discoveries

`sysinfo 0.37.2` computes macOS available memory as `free + inactive + purgeable − compressor pages`, saturating at zero. On the 16 GiB development Mac it returned 0 in every sample (`free 9412, inactive 246247, purgeable 15619, compressor 298047` pages). The branch had changed `None` from "keep UBC" to "direct I/O", so every read-only open on such a host lost UBC. The `macfuse_open_cache` counters describe the `keep_cache` decision only, so the regression was invisible.

`std::sync::RwLock::try_read` on macOS (queue implementation) fails while a writer is queued as well as while one holds the lock. Each such miss fixes direct I/O for the whole life of that handle.

Disabling OS-cache participation for a memory-bypassed handle clears the inode generation (`prepare_os_cache_open_inner`). The next fitting open would then purge pages other handles still reuse, so participation stays enabled.

The Linux adapter has an equivalent sampler with the original full-interval pacing. That crate is `cfg(target_os = "linux")` and cannot be validated on this host.

## Decision Log

- Measure sample age from before the OS call and expire after two intervals (2 s). Missing, zero, or stale samples select direct I/O. Date: 2026-10-14.
- Wait only the remainder of the interval measured from the start of the current sample. An overrun samples immediately without catch-up bursts. Date: 2026-10-14.
- Replace `sysinfo` with `host_statistics64` and `free + speculative + inactive` pages. Do not subtract compressor occupancy; it is not in the reclaimable queues. Exclude purgeable pages, which are also counted in the active/inactive queues. The macFUSE crate drops its `sysinfo` dependency. `mach_host_self` is used once per sampler under `#[expect(deprecated)]` rather than adding `mach2`. Date: 2026-10-14.
- Publish through two atomics: bytes (Relaxed), then a nanosecond timestamp (Release); readers do the reverse with Acquire. A reader that sees a timestamp sees its bytes or newer ones, so no reader ever waits or fails transiently. This supersedes the earlier `RwLock` choice because the user asked to fix all deep-review findings, which named `try_read` misses. Nanoseconds avoid millisecond rounding at the TTL boundary. Date: 2026-10-14.
- `system()` publishes one measurement synchronously before the mount serves callbacks. Tests use `start()`, which runs every sample on the worker, to exercise blocked sampling. Date: 2026-10-14.
- Contain measurement panics with the existing `catch_callback_unwind`, and log only health transitions. Spawn or host-port failure logs at error level. Date: 2026-10-14.
- Add `VfsMacFuseOpenMemoryDirectIo` and two defaultable `macfuse_open_cache` counters. They sit outside `total`, so existing keep/drop semantics and JSON keys stay unchanged. Date: 2026-10-14.
- `CallbackState::wait_for_reply_tasks` only drains replies again. Both teardown paths call `stop_background_work` explicitly afterwards. Date: 2026-10-14.
- Test telemetry is an enum variant (`Telemetry::Fixed`), not a flag on the production path. Date: 2026-10-14.
- Existing commits keep their messages; the branch is already pushed and AGENTS.md forbids rewriting without authorization. New commits use `<type>: <subject>`. Date: 2026-10-14.

## Validation and Acceptance

Tests show the following:

- Missing, zero, failed, and expired samples are unusable.
- A fresh sample keeps kernel I/O through the real `open()` path.
- Oversized files and missing samples select direct I/O and increment their counters.
- Memory direct I/O does not clear the generation used by the next fitting open.
- Opens complete while sampling is blocked.
- The first sample is visible when `system()`/`started()` returns.
- A panicking sample is contained.
- The host API returns a nonzero estimate on this Mac, where `sysinfo` returns zero.
- `stop_background_work`, not reply draining, stops the worker.

Channel handshakes and bounded waits establish the conditions without coordination sleeps.

## Idempotence and Recovery

Tests use isolated contract fixtures and release handles. `shutdown` is idempotent (the worker is taken once; dropping the stop sender ends a pending wait), and `Drop` covers failed mount construction. Preserve unrelated changes and the shared graph artifacts.

## Outcomes & Retrospective

Open callbacks never wait for or contend with memory sampling. On this Mac the native estimate is nonzero, so read-only files that fit keep UBC and readahead; through `sysinfo` they all fell back to direct I/O. Memory-driven direct I/O is now counted. Validation: 16 sampler tests, 21 open-cache tests, 20 `read_only_adapter` tests, the kernel-cache generation test, and 2 VFS stats tests passed. The 7 production lint-policy checks, Clippy with `-D warnings` for both crates, formatting, and diff checks also passed. Live legacy macFUSE/FSKit mounts, the Linux sampler, and full suites were not run. Thread-spawn failure is logged and counted but has no injected test, since std offers no seam for it.
