# Move macFUSE memory sampling out of open callbacks

This living ExecPlan follows `.agent/PLANS.md`.

## Purpose / Big Picture

Concurrent file opens must not queue behind an OS memory measurement. Read-only files use kernel caching only with a fresh estimate showing they fit; missing or stale telemetry selects direct I/O while local VFS payload caching still works.

## Surprises & Discoveries

The Linux adapter already has an owned memory worker with a one-second cadence and two-second expiry. Its sampler is crate-private; extracting a shared subsystem would broaden this fix. macFUSE currently treats missing telemetry as permission for UBC caching. Both legacy and FSKit call `CallbackState::wait_for_reply_tasks` during teardown.

## Decision Log

Use the existing Linux ownership/channel/join pattern locally in macFUSE without new dependencies. Publish value and time with an atomic version to reject mixed snapshots. Return `None` without retrying if publication overlaps a foreground read. Date: 2026-10-14.

Measure sample age from before the syscall and expire after two seconds; zero/missing/stale samples conservatively select direct I/O. Stop and join after callback drain, with Drop as the cleanup fallback. Date: 2026-10-14.

## Context and Orientation

`crates/studiofs-macfuse/src/adapter.rs` routes read-only open/create handles through `open_with_result` and `read_only_open_cache_policy`. The former currently calls a process-global sysinfo snapshot guarded by a mutex. `CallbackState` owns the adapter and drains callbacks in both `lib.rs` and `fskit.rs`. `docs/platform-bridges.md` defines the macOS cache policy. The working branch is `feature/sfs-807-move-macfuse-available-memory-refresh-off-the-open-callback`; initial changes were only the tracked Codebase Memory snapshot and metadata, which must be preserved.

## Plan of Work

Add `adapter/memory_sampler.rs` with a dedicated thread, atomic snapshot, and stop channel. Only the thread owns sysinfo. Store this sampler on `StudioVfsAdapter`, read it from `open_with_result`, and stop it after reply drain. Remove the global mutex/synchronous refresh and old tests that expect refresh from a reader. Document conservative fallback and age limits. Exercise the actual adapter open path while an injected sampling function is blocked on a channel.

## Validation and Acceptance

Tests must show missing, zero and expired samples return no usable estimate, fitting/oversized files retain the expected cache decision, opens complete while sampling is blocked, and shutdown joins the worker before returning. Channel handshakes and bounded waits establish the tested conditions without coordination sleeps. The missing-memory regression failed before the fix with `assertion failed: policy.direct_io`; the old snapshot refreshed its timestamp from the reader.

## Idempotence and Recovery

Tests create isolated contract fixtures and release handles. Worker shutdown is idempotent; Drop handles failed mount construction. Preserve unrelated changes and the shared graph artifacts. No commit, push or PR is requested.

## Interfaces and Dependencies

Reuse existing sysinfo, tracing and std threads/channels/atomics. `SystemMemorySampler` exposes `system`, `start` for deterministic injected sampling, `available_memory`, and idempotent `shutdown`. `StudioVfsAdapter` owns it for the mount lifetime. No public API or dependency changes are needed.

## Outcomes & Retrospective

Independent review found an additional missing-attribute fallback that kept kernel I/O when memory was unavailable. A focused red regression reproduced it and the fallback now selects direct I/O. Changes remain uncommitted for review; existing graph artifacts are preserved.
