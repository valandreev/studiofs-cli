## Surprises & Discoveries

The existing SFS-883 follow-up identifies the third quick-xml version as a
Wayland build-time parser, separate from the two S3 runtime parsers. Document
both scopes. The visible host is macOS ARM64 with stable Rust 1.99.1 and 1.95.0
installed, so local checks cannot establish Windows or Linux native behavior.
The Linear plugin's `get_agent_context` endpoint is advertised but unavailable.
Review corrected the issue's parser-source shorthand: reqsign 0.37 XML is AWS
STS credential data, OpenDAL 0.38 XML is S3 response data, and Wayland 0.39 XML
is build input. StudioFS configures explicit S3 credentials and disables config
and EC2 metadata loading.

An attempt to run tests against the configured PostgreSQL endpoint was rejected
by automatic approval review because its disposability was unverified. No test
ran against that endpoint. The safe replacement created isolated PostgreSQL 18
and RustFS containers, exported explicit loopback destinations taking precedence
over dotenvy, polled real health conditions and removed both containers in a
finally block. Both PG tests and S3 put/get then passed.
