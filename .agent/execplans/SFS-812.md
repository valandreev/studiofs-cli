# Wake macFUSE shutdown and deferred symlink replies on events

This living ExecPlan follows `.agent/PLANS.md`.

## Purpose / Big Picture

An idle macFUSE mount must not wake ten times per second to check shutdown. A symlink whose parent directory is admitted locally but not yet committed must wait for that commit without holding a blocking-pool worker. Explicit unmount, process signals, request cancellation and shutdown must wake the relevant waiter, with the existing five-second parent retry deadline retained.

## Surprises & Discoveries

A callback drain precedes VFS shutdown, so a VFS shutdown token alone cannot release legacy pending symlinks during session teardown; the adapter cancels its namespace reply token before draining. A dormant current-thread runtime can hold an actual deferred parent commit without adding production test hooks. The VFS already owns deferred namespace completion notifications. Legacy and FSKit symlink callbacks currently dispatch through blocking reply workers. Removing only the sleep would leave the worker occupied. The checked-out repository and shell are macOS paths despite the supplied Windows instruction; platform acceptance will be reported from actual executable checks.

## Review refinements (2026-10-15)

The supplied review defines one active mount watcher as the supported scope. Remove the weak-reference broadcast list, dedicated watcher pipe and dual descriptor poll. A single process-owned nonblocking UnixStream pair handles signal, unmount and drop wakeups. The signal handler retains its raw async-signal-safe write, while ordinary wake/drain code uses Read and Write. Consume wake bytes before rechecking the condition so stale wakes cannot make an idle watcher spin.

Both legacy and FSKit symlink requests now obtain a child token from the adapter shutdown token. That makes the extra parent-token check and select branch redundant. Flatten the timeout result, retaining the absolute deadline and error mapping. The shared dormant/callback runtime helpers live in `crates/studiofs-macfuse/src/test_support.rs`, enabled only for tests.

Keep the VFS shutdown-aware wrapper separate. The base waiter also serves local dirty flush, fsync and release barriers; making its waits cancel on background shutdown would alter local durability behavior. This review suggestion is rejected on contract grounds.
