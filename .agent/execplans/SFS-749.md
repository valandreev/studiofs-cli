# Delegate POSIX access checks to the native kernel

This living ExecPlan follows `.agent/PLANS.md`.

## Purpose / Big Picture

A mounted caller must receive access decisions from its own owner, primary or supplementary group, or other permission class. Directory search requires execute permission. Native kernel checks preserve platform root and capability semantics without reconstructing credentials in userspace.

## Surprises & Discoveries

The legacy macFUSE operation table does not register access. Its `defer_permissions` mount option permits all operations. The adapter's union predicate is used by FSKit, not the legacy mount. The graph generation is old and the changed paths were read directly after checking coverage.

## Decision Log

- Decision: Use `default_permissions` on Linux, legacy macFUSE and FSKit; remove union-of-classes checks.
  Rationale: Both libfuse and macFUSE document kernel permission delegation. The kernel retains full caller credentials and platform root/capability semantics. This is smaller and more reliable than gathering supplementary groups separately.
  Date/Author: 2026-09-29 / Codex.
- Decision: Validate both adapters with one shared test-only access table and native mounts. A fixture seeds differing inode owners/groups so the test can exercise all classes without privileged credential changes.
  Rationale: Mount arguments alone cannot prove access(2) decisions. Root is explicitly rejected as a test caller because it bypasses ordinary classes.
  Date/Author: 2026-09-29 / Codex.

## Context and Orientation

`crates/studiofs-linux-fuse/src/low_level.rs` builds libfuse arguments and registers Rust callbacks through `csrc/low_level_ops.c`. `crates/studiofs-macfuse/src/low_level.rs` builds legacy mount options; `src/fskit.rs` builds FSKit options and dispatches wire requests. Both return local VFS inode attributes; legacy root uid/gid are mapped to the mount user by the existing bridge conversion. Kernel permission checking consumes these exposed attributes. PostgreSQL remains outside the foreground path.

## Plan of Work

First observe the newly added macOS mount-option and native table regressions fail. Add Linux `default_permissions`; replace macOS `defer_permissions` with it in both mount backends. Remove the Linux access registration and both union predicates. FSKit must reject unexpected access requests rather than acknowledge them through ENOSYS, which can imply permanent success. Update the platform contract and tests to describe kernel delegation.
