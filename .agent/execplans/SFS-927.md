## Surprises & Discoveries

- Early mounted configs accidentally pointed to a stale debug binary. Those runs are not evidence. The later clean registered runs used `target/release/studiofs`, with runner metadata confirming the product path.
- Clean release runs failed generic/001 with stale chain names. Targeted lookup instrumentation showed a serving entry restored by self replay after a local rename; the replay context could predate the local event.
- Replay context is sampled before the Redb write transaction is opened. A foreground rename can commit before replay starts, leaving the captured `next_event_seq` and overlay stale. The replay had applied the earlier self create to base and serving without protecting/reapplying the newer rename suffix.
- The red stale-context regression fails if suffix rebase is removed, even with the refreshed transaction counters. The refreshed bound and final namespace rebase are both required.
- The suffix reducer handles actual unlink event shape, including `RemoveRegularFileGraph` and `RemoveAttr`, by clearing indexed aliases while preserving later replacement bindings.
- The first rebuilt run after the replay-bound fix still failed generic/001. A second red regression isolated local range completion advancing over a published self-batch prefix before its PG version applied. The shared cursor calculation now blocks at outstanding published intervals and permits advancement once their version applies.
- Review finding 1 reproduced: self replay left the locally unlinked inode readable through `get_attr` after the earlier create entered `base_inodes`.
- Review finding 2 reproduced: a transaction-refreshed event bound newer than captured context yielded no acknowledged prefix (`None` instead of `Some(end)`).
- The existing held-barrier regression `foreign_rename_removes_published_local_loser_across_cursor_gap` covers a published local rename losing to a foreign rename and remains green after filtering the rebase suffix.
- The added draft-unlink regression passes with no `InvalidationIntent::Entry`; the inode assertion now passes with `MetaError::InodeNotFound`.
- Self-prefix acknowledgment uses the transaction-refreshed upper bound only after appended-overlay conflict discovery has used the captured lower bound; the full replay suite passes with this ordering.

## Decision Log

- Decision: Require a deterministic mounted reproduction before changing invalidation behavior.
  Rationale: Linux VFS can invalidate its own dentries after successful callbacks, so missing notification is not yet proven as the cause.
  Date/Author: 2026-10-31 / GPT-6-Luna-Medium.
- Decision: Investigate the local/replicated metadata state that serves the positive lookup before changing the Linux invalidation adapter.
  Rationale: The reduced run reached the FUSE lookup callback and it returned success after a successful unlink; this is a userspace namespace result.
  Date/Author: 2026-10-31 / GPT-6-Luna-Medium.
- Decision: Rebase only pending namespace events that are not already published or completed, and include their keys in reconciliation protection.
  Rationale: Replaying published local history can overwrite later remote namespace decisions; reconciling a draft unlink before applying its tombstone can expose a transient name and journal an unnecessary invalidation.
  Date/Author: 2026-10-31 / GPT-6-Luna-Medium.
