## Surprises & Discoveries

The sandbox hides `/dev/fuse`; an escalated host check confirms a readable and
writable device on kernel `7.0.0-42-generic`. The issue's recorded kernel was
`7.0.0-38-generic`, so retain the actual kernel with new measurements.

Codebase Memory has two names for this checkout; discovery used
`home-val-dev-studiofs-cli`, with direct inspection of replay source. Linear's
get_agent_context endpoint returns tool-not-found; issue reads work.

The fresh main run failed in 29 seconds at `sub/l.3` (iteration 4), then
`sub/d.0`. The SFS-927 merge failed in 20 seconds at `sub/l00.4` (iteration 2),
then `sub/j00.0` and `sub/d.0`. Thus the proposed bisect interval lacks a
confirmed good endpoint.

A tentative recent-flush counterexample could reproduce stale serving state
only by combining publications serialized by `replication_lock` in production.
That test was removed rather than treating an unreachable schedule as proof.

## Decision Log

Do not attribute the failure to SFS-946 without evidence. That issue concerns a
completed local-only empty-file create disappearing. Generic/001 reports a
removed nonempty name returning. Compare actual event histories first.

## Outcomes & Retrospective

Both main and the proposed good endpoint fail registered generic/001 on fresh
volume pairs. A later regression is unproven; the SFS-927 merge itself remains
affected. Pending serving replay deterministically restores the renamed source
when base still holds it: its supplement restored only the destination. The
minimal correction adds the missing source removal to that same supplement.
Focused tests pass; the clean rebuilt release passes registered generic/001
on three fresh pairs. No diagnostic instrumentation remains. The user-reported
WSL2 success has not been independently inspected because remote environment
link tools are unavailable; the deterministic redb regression does not depend
on a kernel or FUSE implementation.

define disposable TEST/SCRATCH volume names, isolated client state, and a fresh

bindings. `metadata_sync.rs` commits replay position atomically and restores
pending serving state using `replication_flush.rs`. Existing regressions are in
`pg_engine/tests/remote_apply.rs`. SFS-927's previous result is documented in
`.agent/execplans/SFS-927.md`.
