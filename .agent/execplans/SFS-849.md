## Surprises & Discoveries

The workspace still declares deprecated `GPL-3.0` and has no root LICENSE. These
are already within the parent licensing programme, not a reason to change the
product's license as part of this inventory. Cargo metadata covers every lock
entry, including non-Windows dependencies. The Linear shared-agent-context tool
advertised in this session returns “Tool get_agent_context not found”. Context7
CLI/MCP is unavailable; current official Cargo documentation is the fallback.

There are 39 original third-party license expressions. All 640 registry archives
match lock checksums and 1,703 evidence members match the archives. There are 65
registry packages without a named standalone license/notice file, including 29
in at least one product graph; the report lists each unresolved notice item.
Jemalloc's native BSD license is additional to its wrapper license label.

Independent review found fail-open tree parsing and overconfident checksum-map
fallback verification. Unknown tree lines now fail; archive evidence members must
exist and match. Checksum-map-only fallback remains explicitly unresolved for
archive verification. Focused self-tests cover those cases. Final graph coverage
MCP returned transport closed; new artifacts were inspected directly.
