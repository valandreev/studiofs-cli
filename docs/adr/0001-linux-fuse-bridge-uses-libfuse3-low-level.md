# Linux FUSE Bridge Uses libfuse3 Low-Level API

StudioFS Linux mount targets the Linux VFX reference platforms: Ubuntu 24.04 LTS and above, plus Rocky Linux 9.4 and above, with Rocky Linux 8.6 and above treated as best-effort compatibility. We will build the Linux platform bridge on the libfuse3 low-level API first, because it keeps inode-based callback control while delegating mature FUSE mount/session transport to the reference userspace library. `direct` cache policy is the operational rollback for the production libfuse3 bridge; a custom raw `/dev/fuse` transport is not maintained. `fuser` remains a baseline/comparison path, not the production candidate.
