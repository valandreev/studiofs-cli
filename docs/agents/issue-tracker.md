# Issue tracker: Linear

Issues and specs for this repo live in Linear. Use the configured Linear plug-in for all issue-tracker operations.

## Conventions

- Create, read, list, update, assign, comment on, and close issues through the Linear plug-in.
- Write Linear issue content in English.
- When a skill says to publish to the issue tracker, create or update a Linear issue.
- When a skill says to fetch a relevant ticket, retrieve it through the Linear plug-in.
