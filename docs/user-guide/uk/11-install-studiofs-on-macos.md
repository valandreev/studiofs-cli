# 11. Встановлюємо StudioFS на macOS
> **Сторінка в процесі доповнення**

На Mac робота зі StudioFS теж починається з термінала. Після підключення ви працюватимете з папкою у Finder, монтажній програмі чи програмі для композитингу, але спершу потрібно встановити два окремі компоненти: **macFUSE**, який дає macOS змогу підключити файлову систему, і сам **StudioFS**.

## Спочатку macFUSE

Зараз на macOS StudioFS працює насамперед через **macFUSE**. Саме його ми й використовуватимемо далі.

Завантажте інсталятор з [офіційного сайту macFUSE](https://macfuse.github.io/) і виконайте всі його кроки. Якщо ви користуєтеся Homebrew, той самий компонент можна встановити командою:

```bash
brew install --cask macfuse
```

### Дозволи macOS

Встановлення пакета й дозвіл на роботу його системного компонента — це різні кроки. macOS може попросити підтвердити завантаження розширення в **System Settings → Privacy & Security** («Системні параметри → Приватність і безпека»), а потім перезапустити Mac. Назви й розташування пунктів залежать від версії macOS, тому орієнтуйтеся на повідомлення інсталятора та [інструкцію macFUSE](https://github.com/macfuse/macfuse/wiki/Getting-Started).

Стандартний macFUSE версії 5.4 протестовано на macOS 27 Golden Gate і macOS 26 Tahoe. На Mac з Apple silicon для нього може знадобитися дозвіл на сторонні розширення ядра, який вмикають у середовищі відновлення: **Startup Security Utility → Reduced Security → Allow user management of kernel extensions from identified developers**. Це змінює політику безпеки комп’ютера. Дотримуйтеся актуальної інструкції macFUSE саме для вашої системи, а на студійному Mac попередньо узгодьте цей крок із системним адміністратором. Якщо корпоративна політика його забороняє, не намагайтеся обійти її командами з випадкового форуму.

## Завантажуємо StudioFS

Відкрийте [сторінку випусків StudioFS](https://github.com/valandreev/studiofs-cli/releases) і завантажте збірку для свого Mac — **Apple silicon** або **Intel**. Якщо файл запаковано в архів, розпакуйте його. У команді `install` замініть `/path/to/studiofs` на шлях до завантаженого виконуваного файлу:

```bash
mkdir -p "$HOME/.local/bin"
install -m 755 "/path/to/studiofs" "$HOME/.local/bin/studiofs"
export PATH="$HOME/.local/bin:$PATH"
studiofs --version
studiofs --help
```

Команда `export` діє лише в поточному терміналі. Щоб налаштування зберігалося, додайте цей рядок до `~/.zshrc` (якщо використовуєте стандартну оболонку zsh) і відкрийте нове вікно термінала. Перевірте, яку копію програми знаходить система:

```bash
command -v studiofs
studiofs --version
```

## Готуємо місце для підключення

Точку монтування для macFUSE створимо в `/Volumes/Studiofs/`. Оскільки це системний каталог, створіть папку з правами адміністратора й зробіть її власником свого користувача:

```bash
sudo mkdir -p /Volumes/Studiofs
sudo chown "$(id -un):$(id -gn)" /Volumes/Studiofs
ls -A /Volumes/Studiofs
```

Команда `ls` має показати, що папка порожня. Якщо там уже є файли, оберіть для точки монтування інше ім’я. Не підключайте том поверх каталогу з матеріалами поточного проєкту: після монтування його звичайний вміст буде приховано, доки том не відключать.

У прикладі том називається `myvolume`. StudioFS додає цю назву до `/Volumes/Studiofs/`, тож фактичний шлях буде `/Volumes/Studiofs/myvolume`. Кеш зберігайте окремо на локальному SSD, а не всередині підключеного тому.

## Перший запуск: що вже можна перевірити

Якщо `studiofs --help` працює, отже, виконуваний файл запускається. Але це ще **не перевіряє монтування чи дозволів macFUSE**.

Після того як ви створите том командою `init` або підключите наявний том командою `discover`, команда монтування виглядатиме так:

```bash
studiofs mount myvolume /Volumes/Studiofs --foreground
```

Цей приклад передбачає, що локальний клієнт для тому `myvolume` уже підготовлено. Якщо ні, спершу виконайте кроки з [глави 13](13-create-your-first-volume-studiofs-init.md) або [глави 16 про другий комп’ютер](16-connect-a-second-computer-studiofs-discover.md). Не створюйте новий том замість того, до якого вас запросила команда.

Не закривайте термінал, у якому запущено монтування. В іншому вікні можна відкрити папку у Finder:

```bash
open /Volumes/Studiofs/myvolume
```

Перше читання й запис перевіряйте на тестових матеріалах, як описано в главах 14–15. Перед відключенням закрийте файли й програми, які використовують том, а потім виконайте:

```bash
studiofs umount /Volumes/Studiofs/myvolume
```

Якщо macFUSE відхиляє монтування, ще раз перевірте системні дозволи й перезапустіть Mac. Якщо StudioFS повідомляє, що тому немає або що немає доступу до PostgreSQL чи S3, перевірте відповідні налаштування: перевстановлення драйвера не виправить неправильного пароля до бази.
