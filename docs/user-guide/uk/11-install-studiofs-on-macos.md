# 11. Встановлюємо StudioFS на macOS

На Mac StudioFS теж починається з термінала. Після підключення ви працюватимете з папкою у Finder, монтажній програмі чи композері, але спочатку потрібно встановити дві окремі речі: **macFUSE**, який допомагає macOS підключити файлову систему, і сам **StudioFS**.

## Спочатку macFUSE

Основний шлях StudioFS на macOS зараз — **macFUSE**. Саме його використовуємо далі.

Завантажте інсталятор з [офіційного сайту macFUSE](https://macfuse.github.io/) і пройдіть його кроки. Якщо вже користуєтеся Homebrew, можна встановити той самий компонент командою:

```bash
brew install --cask macfuse
```

### Дозволи macOS

Встановлення пакета й дозвіл на роботу його системного компонента — різні кроки. macOS може попросити підтвердити завантаження розширення в **System Settings → Privacy & Security** («Системні параметри → Приватність і безпека»), а потім перезапустити Mac. Назви й розташування пунктів залежать від версії macOS; орієнтуйтеся на повідомлення інсталятора та [інструкцію macFUSE](https://github.com/macfuse/macfuse/wiki/Getting-Started).

Звичайний macFUSE версії 5.4 тестували на macOS 27 Golden Gate та macOS 26 Tahoe. На Mac з Apple silicon для звичайного macFUSE може знадобитися дозвіл на сторонні розширення ядра через середовище відновлення: **Startup Security Utility → Reduced Security → Allow user management of kernel extensions from identified developers**. Це зміна політики безпеки комп’ютера. Дотримуйтеся актуальної інструкції macFUSE саме для вашої системи, а на студійному Mac узгодьте її із системним адміністратором. Якщо корпоративна політика забороняє цей крок, не намагайтеся обійти її командами з випадкового форуму.

## Завантажуємо StudioFS

Відкрийте [сторінку випусків StudioFS](https://github.com/valandreev/studiofs-cli/releases) і завантажте збірку для свого Mac — **Apple silicon** або **Intel**. Якщо файл упаковано в архів, розпакуйте його. У команді `install` замініть `/path/to/studiofs` на шлях до завантаженого виконуваного файла:

```bash
mkdir -p "$HOME/.local/bin"
install -m 755 "/path/to/studiofs" "$HOME/.local/bin/studiofs"
export PATH="$HOME/.local/bin:$PATH"
studiofs --version
studiofs --help
```

`export` діє для поточного термінала. Для постійного налаштування додайте цей рядок до `~/.zshrc`, якщо використовуєте стандартний інтерактивний zsh, і відкрийте нове вікно термінала. Перевірте, яку копію програми знайшла система:

```bash
command -v studiofs
studiofs --version
```

## Готуємо місце для підключення

Точку монтування для macFUSE створимо в `/Volumes/Studiofs/`. Оскільки це системний каталог, створіть папку з правами адміністратора й передайте її у власність свого користувача:

```bash
sudo mkdir -p /Volumes/Studiofs
sudo chown "$(id -un):$(id -gn)" /Volumes/Studiofs
ls -A /Volumes/Studiofs
```

Після `ls` папка має бути порожньою. Якщо там уже є файли, оберіть інше ім’я для точки монтування. Не підключайте том поверх каталогу з матеріалами поточного проєкту: після монтування його звичайний вміст буде прихований до відключення.

У прикладі том називається `myvolume`. StudioFS додає цю назву до `/Volumes/Studiofs/`, тож фактичний шлях буде `/Volumes/Studiofs/myvolume`. Кеш зберігайте окремо на локальному SSD, не всередині підключеного тому.

## Перший запуск: що вже можна перевірити

Якщо `studiofs --help` працює, виконуваний файл запускається. Це ще **не перевірка монтування чи дозволів macFUSE**.

Після створення тому через `init` або підключення наявного тому через `discover` команда виглядатиме так:

```bash
studiofs mount myvolume /Volumes/Studiofs --foreground
```

Цей приклад розрахований на вже підготовлений локальний клієнт тому `myvolume`. Без нього спочатку пройдіть главу 13 або [главу 16 про другий комп’ютер](16-connect-a-second-computer-studiofs-discover.md). Не створюйте новий том замість того, до якого вас запросила команда.

Залиште термінал із монтуванням відкритим. В іншому вікні можна відкрити папку у Finder:

```bash
open /Volumes/Studiofs/myvolume
```

Першу перевірку читання й запису робіть на тестових матеріалах за главами 14–15. Перед відключенням закрийте файли й програми, які використовують том, а потім виконайте:

```bash
studiofs umount /Volumes/Studiofs/myvolume
```

Якщо macFUSE відхиляє монтування, поверніться до системних дозволів і перезапуску. Якщо StudioFS повідомляє про відсутній том, доступ до PostgreSQL чи S3, перевіряйте відповідні налаштування: перевстановлення драйвера не виправить пароль до бази.
