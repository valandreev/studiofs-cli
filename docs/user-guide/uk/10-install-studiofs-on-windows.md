# 10. Встановлюємо StudioFS на Windows
> **Сторінка в процесі доповнення**

На монтажній станції StudioFS складається з двох частин: програми `studiofs.exe` і WinFSP — компонента Windows, завдяки якому програма може показати том як диск. Спершу встановимо обидві частини й перевіримо, чи все запускається. Підключати S3 і створювати том будемо пізніше: сам по собі диск не з’явиться лише тому, що ви завантажили програму.

Усі команди нижче виконуються в **PowerShell у самій Windows**, а не всередині WSL. Приклади розраховано на Windows x64. Те, що код підтримує інші архітектури, ще не означає, що для вашого комп’ютера є готова збірка.

## Спочатку WinFSP

Завантажте й встановіть **WinFSP 2026 або новішу версію** зі [сторінки випусків в офіційному репозиторії WinFSP](https://github.com/winfsp/winfsp/releases). StudioFS використовує кілька нових можливостей WinFSP, тому попередні версії не підтримуються. Windows може запитати права адміністратора, оскільки встановлюється драйвер файлової системи. Якщо інсталятор пропонує перезавантажити комп’ютер, зробіть це, перш ніж перевіряти StudioFS. На робочій станції з обмеженими правами цей крок краще доручити адміністраторові.

## Завантажуємо StudioFS

Відкрийте [сторінку випусків StudioFS](https://github.com/valandreev/studiofs-cli/releases) і завантажте збірку для **Windows x64**. Якщо файл запаковано в архів, розпакуйте його в окрему папку. Скопіюйте всі файли випуску до папки StudioFS у своєму профілі:

```powershell
$studiofsBin = Join-Path $env:LOCALAPPDATA 'Programs\StudioFS'
New-Item -ItemType Directory -Force -Path $studiofsBin | Out-Null
Copy-Item 'C:\path\to\extracted\release\*' -Destination $studiofsBin -Recurse
& (Join-Path $studiofsBin 'studiofs.exe') --version
& (Join-Path $studiofsBin 'studiofs.exe') --help
```

У команді `Copy-Item` замініть `C:\path\to\extracted\release` на шлях до розпакованої папки випуску. Якщо до випуску додано окремі інструкції, дотримуйтеся їх.

## Як не вводити щоразу повний шлях

У параметрах Windows знайдіть пункт **«Змінення змінних середовища для облікового запису»**, відкрийте змінну користувача **Path** і додайте до неї папку, шлях до якої показує команда `$studiofsBin`. Додавайте саме папку, без `studiofs.exe`, і не видаляйте наявних записів. Щоб змінити Path свого користувача, не потрібно встановлювати програму для всіх користувачів.

Закрийте PowerShell і відкрийте нове вікно. Якщо ви працюєте у Windows Terminal і нова вкладка зберігає старі змінні середовища, перезапустіть увесь Terminal. Тепер перевірте:

```powershell
Get-Command studiofs
studiofs --version
studiofs --help
```

`Get-Command` показує, який саме файл буде запущено. Це корисно, коли на станції залишилася стара копія програми. Зверніть увагу: щоб запустити програму з поточної папки, PowerShell вимагає писати `.\` перед її назвою, тобто `.\studiofs.exe --help`, або вказувати повний шлях. Перед шляхом у лапках потрібен оператор `&`, як у прикладі вище.

## Права й перший запуск

Після встановлення драйвера працюйте у звичайному PowerShell під тим обліковим записом, у якому запускаєте монтажну програму. Не вмикайте «Запуск від імені адміністратора» за кожної помилки: сеанс із підвищеними правами та звичайний сеанс можуть бачити підключені диски по-різному.

Обліковий запис повинен мати право запису в локальні папки стану й кешу StudioFS. Для кешу також потрібне вільне місце на локальному диску. Захищена системна папка чи мережевий ресурс — невдалий вибір для першої перевірки. Доступ до S3 і PostgreSQL визначається окремими обліковими даними, і права адміністратора Windows їх не замінюють.

Якщо під час запуску з’являється повідомлення про відсутню DLL WinFSP, перевірте, чи встановлено WinFSP, чи він лежить за стандартним шляхом і чи відповідає архітектура. Якщо Windows блокує завантажений файл, перевірте його джерело й зверніться до адміністратора відповідно до правил студії. Для запуску `studiofs.exe` не потрібно змінювати PowerShell Execution Policy: це налаштування стосується сценаріїв, а не встановлення драйверів.

**Якщо довідка відкривається, клієнт готовий до налаштування.**
