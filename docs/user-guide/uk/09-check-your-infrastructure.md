# 09. Перевіряємо інфраструктуру

Перед встановленням StudioFS перевірте, що з робочого комп’ютера доступні всі потрібні компоненти:

- [ ] **Tailscale** підключений, сервер доступний у приватній мережі.
- [ ] **PostgreSQL** доступний, облікові дані та потрібні права підготовлено.
- [ ] **S3** доступний за правильними endpoint і bucket; ключі мають потрібні права.

Якщо всі пункти виконано, переходьте до встановлення для своєї системи: [Windows](10-install-studiofs-on-windows.md), [macOS](11-install-studiofs-on-macos.md) або [Linux](12-install-studiofs-on-linux.md).
