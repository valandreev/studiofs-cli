# Scope / Призначення

This directory contains practical documentation for people installing and using
StudioFS. Implementation contracts, architecture, and developer reference remain
in the existing `docs/` locations and are listed separately in the repository's
[README](../../README.md#technical-contracts-and-developer-reference).

Цей каталог містить практичний посібник для встановлення та використання StudioFS.
Контракти реалізації, архітектура й довідкові матеріали для розробників залишаються
за наявними шляхами в `docs/` і перелічені окремо в
[README репозиторію](../../README.md#technical-contracts-and-developer-reference).
